## Tentang saya

Saya tertarik pada **backend development**, aplikasi **sistem informasi geografis (GIS)**, serta **analisis data**. Saya belajar melalui proyek: dari website profil desa dan peta interaktif hingga eksperimen algoritma dan machine learning.

- **Web & backend:** mengembangkan aplikasi dengan PHP, Laravel, React, dan Next.js.
- **Geospatial:** mengolah informasi lokasi dan membangun pengalaman peta interaktif dengan Leaflet.
- **Data & algoritma:** mengeksplorasi Python, visualisasi data, model prediksi, dan optimasi.
